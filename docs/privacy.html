GitLab Image Viewer

Privacy Policy

Last updated: 22 November 2026

GitLab Image Viewer is a browser extension that shows the images in a GitLab repository folder as a thumbnail grid. This page explains exactly what it does with your data.

The short version

No data is collected. The extension has no analytics, no telemetry and no servers of its own. Nothing about you, your repositories or your browsing is transmitted anywhere.

What is stored, and where

  • Grid settings. Thumbnail size, images per row, show names, hide file list, and whether the grid is open are saved with chrome.storage.local in your own browser profile.
  • Self-hosted instances. If you add a GitLab address on the settings page, that origin is stored locally so the extension can keep working there after a restart.

Both are local to your browser. They are not synced to a server by this extension, and they are removed when you uninstall it.

Network requests

Thumbnails are loaded from the same GitLab instance whose folder you are viewing, by requesting the file's raw URL. This uses your existing browser session, so images in private projects load the same way they do when you open them in GitLab. No token, OAuth flow or password is involved.

The extension contacts no other domain. It does not phone home, and it does not load remote code.

Permissions

  • storage — remember your grid settings and your self-hosted instance list.
  • scripting — register the content script for a self-hosted GitLab origin you have approved.
  • Access to https://gitlab.com/* — add the thumbnail grid to GitLab folder pages.
  • Optional access to a self-hosted origin — requested only when you type an address into the settings page and confirm it. Access is limited to that one origin, and you can revoke it at any time from your browser's extension settings.

What the extension does not do

  • It does not read, collect or transmit your GitLab credentials, cookies or tokens.
  • It does not track which pages you visit.
  • It does not modify files, repositories or project settings.
  • It does not sell or share data with third parties.

Changes to this policy

If a future version changes how data is handled, this page will be updated before that version is published, and the date at the top will change.
