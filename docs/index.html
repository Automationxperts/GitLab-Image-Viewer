FAQ

Questions, answered.

How do I see image thumbnails in a GitLab repository?

Install GitLab Image Viewer, then open any folder on gitlab.com or your self-hosted GitLab. Every PNG, JPG, GIF, SVG, WebP, AVIF, BMP and ICO file in that folder appears as a thumbnail grid above the file list.

Does it work with self-hosted GitLab?

Yes. Open the extension settings and add your GitLab address. The extension requests access only to that origin, then adds the thumbnail grid there too. GitLab installed under a subpath is supported.

Does it work with private projects?

Yes. Images load through your normal GitLab browser session, so anything you can open in GitLab shows as a thumbnail. No token or OAuth is needed.

Does the extension collect any data?

No. It has no analytics and no server. The only thing it stores is your grid settings and the self-hosted instances you add, in your own browser.

Why do I only see images from one folder?

The grid shows the folder you are viewing. GitLab paginates large folders, so very large directories may load in pages. The grid follows whatever rows GitLab has rendered.

Which browsers are supported?

Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi and other Chromium-based browsers.

Can I still open the file page?

Yes. Ctrl-click or middle-click a thumbnail to open GitLab's file page in a new tab, or click the file name inside the lightbox.
